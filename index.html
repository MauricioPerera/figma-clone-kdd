Arquitectura y Características

Diseñado sin Compromisos

Cada módulo fue desarrollado bajo contratos estrictos y validación continua para asegurar estabilidad máxima en cliente.

⚡

100% Client-Side

Cero dependencias de servidor, bases de datos o backend en la nube. Despliegue con 1 clic en GitHub Pages vía ramas estáticas.

📐

Lienzo Vectorial Infinito

Pan y zoom centrado en cursor, frames/artboards anidados, 8 primitivas vectoriales, rotación, radio de esquinas interactivo y smart guides magnéticas.

🎨

Conversor a Tailwind CSS

Inspecciona cualquier figura o frame y obtén instantáneamente el código HTML con clases utilitarias de Tailwind CSS listo para copiar.

🤖

WebMCP Standard Ready

Integrado con FastWebMCP. Expone 10 herramientas imperativas y formularios declarativos para que agentes de IA colaboren en el diseño.

📜

Gobernanza KDD

Estructurado según la metodología de Mauricio Perera. 12 nodos OKF enlazados y 5 contratos CCDD validados determinísticamente por scripts locales.

💾

Persistencia & Exportación

Auto-guardado en LocalStorage, pila Undo/Redo inmutable, exportación a SVG vectorial, renderizado PNG Retina 2x y archivos .figma.json.

Metodología • MauricioPerera/KDD

Desarrollo Guiado por Conocimiento (KDD)

Este proyecto no es solo código suelto: cada función y componente está formalmente respaldado por un nodo en la base de conocimiento knowledge/ y gobernado por un contrato de tarea CCDD congelado.

python scripts/validate_okf.py 12/12 PASS
python scripts/validate_contracts.py 5/5 PASS
